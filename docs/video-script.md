# 介绍视频口播稿

配合 `deck/TRAE-K2.pptx`。语速正常大约 **6–8 分钟**。每页对应幻灯片备注，也可直接照这里读。

---

**1. 开场**  
大赛发的不只是一张纸质门票。很多人手里都有这块透明工牌。今天把它变成一个真正能用的东西：口袋里的闪电说和 PPT 遥控器。

**2. 人人都有**  
同一款硬件，ESP32-C3，彩屏，右边三个键。出厂是电子名片。我们不改电路，只换脑子。

**3. 从门票到遥控器**  
刷完之后，它在 Windows 里就是一块蓝牙键盘，名字叫 TRAE K2。没有伴侣程序，没有网页，没有账号。

**4. 三个键**  
上面两个键负责干活，最下面确认键负责换挡。短按立刻切模式，屏幕上会写得清清楚楚；长按才回菜单。

**5. 为什么是键盘**  
闪电说不吃模拟按键。脚本、SendInput、工牌自己录音，这条路我们走过，不行。它要的是真的 HID。所以工牌只发右 Ctrl 和回车，声音走电脑麦克风。

**6. 闪电说档**  
开机默认蓝色 Shandian。上键开始说、再按结束；下键回车。开会、写稿、随口记，都可以。

**7. PPT 档**  
短按确认，标题变成橙色 PPT。上键上一页，下键下一页。同一块牌子，讲稿和翻页都在右手边。

**8. 现场 30 秒**  
插上电，Windows 设置里添加 TRAE K2，屏上变 Connected。不用 PIN。网页上那个 k 不是配对码。

**9. 开源**  
仓库里有预编译固件，也有源码。更重要的是给 Agent 的说明书：另一台电脑、另一个人、另一个助手，拿到这块板，能从零做完备份、烧录、配对、验收。

**10. 结束**  
同一块通行证。你可以继续当名片，也可以让它开始干活。GitHub 在最后一页。
